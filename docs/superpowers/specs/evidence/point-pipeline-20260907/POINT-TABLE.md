## 真机通信异常

第一段0..5首次有效，原值 `[3,0,0,0,0,0]`；第二段27..35首次收到1字节残帧 `fc`，按原策略重试后获得CRC有效帧，原值 `[3,0,11,11,10,0,0,0,0]`。共3次只读请求、1次重试、0次设备寄存器写入。异常帧未作为有效值入库；不能据此宣称线路长期稳定，也不能确定残帧的物理原因。
