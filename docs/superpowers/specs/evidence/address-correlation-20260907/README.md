## 预先定义的判定规则

1. 按TX/RX配对，先核对从站、功能码、字节数、CRC及顺序。区分请求地址与仅由响应位置推定的地址。
2. 比较第2帧各位置与第1/3帧位置6..26；比较第5帧与第4/6帧位置9..17。前后参考不一致的位置记为动态/未决，不从单次不同值断言地址错误。
3. 前后参考相同但分段不同，记录为“本轮地址相关性不一致”；如果分段反而匹配参考前缀，记录为“零起点响应假设得到支持”，不是固件根因已确认。
4. 若所有有效对照相同，但目标切片与零起点前缀也完全相同，则数据缺乏区分能力，不能算作地址语义确认。前后参考相同也不排除中间瞬态，需保留此限制。
5. 一致性检查通过只支持本轮地址行为，不证明设备型号、固件版本、物理量、单位、符号或倍率。不得把1000℃、9.9Hz的旧表试算当作真实测量值，也不得以更换倍率掩盖错位。
