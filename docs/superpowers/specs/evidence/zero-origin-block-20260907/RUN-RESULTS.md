## 未决问题与下一步

1. 非零起点响应错位：本轮仅支持“从零起点整读可获得完整帧”，不能据此恢复通用分段轮询。需要设备协议/固件确认起始地址处理方式。
2. 点位语义：旧数据库46行只是BCMM/CBMM候选。仍缺与当前设备/固件绑定的点表或独立物理参照，不能推定型号、符号、倍率和单位。旧42个FC3的s16仍不受当前软件支持，4个FC1的地址/RBit冲突仍未验证。
3. 首次超时及动态值：本轮记录1次零字节超时，随后重试成功；位置2..4、17、19..24出现变化。原因和合理范围未确认。后续需要单独设计和授权通信稳定性/已知输入对照实验。
4. 正式采集与数据库验收：尚不具备资格/审批、点表和类型支持等前置条件；本轮未开启持续采集、未配置生产点位、未进行新的生产写库测试。旧隔离库回放结果不能替代实机端到端验收。

下一步需要能关联这台自研设备的通讯协议或固件资料；若无资料，则需要现场人员配合一次已知测量量/状态变化，并记录独立读数，才能逐点建立含义和倍率证据。这些不是继续扩大软件读取范围就能自动推导出的事实。
