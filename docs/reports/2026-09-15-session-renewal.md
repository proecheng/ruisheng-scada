# 登录自动续期与24小时重新登录周期

用户要求在目标机补齐自动续期，并将必须手动重新登录的周期设为24小时。

## 行为

- 首次登录由服务端记录固定24小时会话截止时间；访问凭证默认15分钟，浏览器提前1分钟续期。续期、刷新页面和持续操作均不延长24小时截止时间。
- 同窗口并发请求合并续期；支持 Web Locks 的同源多窗口共享一次凭证轮换，并同步续期和退出。目标桌面 localhost 入口支持此机制。
- 临时网络错误保留登录与已显示数据，恢复后重试。凭证拒绝或会话到期才返回登录。续期后实时连接切换为新凭证。
- 退出会撤销当前续期凭证；进行中的响应不会把已退出的会话恢复。后台采集和入库独立于浏览器登录状态。

配置与兼容性说明见 [auth-session.md](../auth-session.md)。普通远程 HTTP 来源不提供 Web Locks 时，仅保证单窗口的续期合并。
