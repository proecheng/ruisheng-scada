# 登录自动续期与24小时上限

访问凭证默认15分钟，浏览器在到期前1分钟自动续期。首次登录时由服务器记录固定的 session_exp，默认首次登录后24小时；每次续期保留原截止时间，并将新访问凭证及续期凭证的有效期限制在该时间以内。达到24小时必须重新登录，刷新网页、持续操作或反复续期都不会延长该时间。

服务端配置为 API_JWT_ACCESS_TTL_SEC（默认900秒）、API_JWT_REFRESH_TTL_SEC（默认604800秒，但实际受会话截止时间限制）和 API_JWT_SESSION_TTL_SEC（默认86400秒）。它们读取自API容器环境；只改宿主机环境文件但未映射到容器不会生效。升级前的旧续期凭证最多使用至该凭证原签发时间后24小时。

前端统一处理主动续期与401后的恢复；同一窗口的并发请求共用一次续期。支持 Web Locks 的浏览器以来源内共享锁协调多个窗口，并通过浏览器存储同步新凭证或退出登录。非安全HTTP来源不提供 Web Locks 时仅保证窗口内合并；建议使用目标机 localhost 桌面入口或 HTTPS。服务器使用原子操作限制每个续期凭证只能轮换一次。

短暂网络错误保留登录状态和已显示数据，恢复后继续续期；续期凭证被拒绝或达到24小时上限才返回登录。自动重试保留原请求的幂等键。续期后的实时连接使用新访问凭证；服务端也会在凭证或会话到期时关闭旧实时连接。显式退出会提交当前续期凭证以撤销它，进行中的续期响应不能恢复已退出的会话。

登录状态仅决定页面访问权限，不控制采集网关及数据库服务。登录到期、退出或关闭网页不会停止后台采集；目标机与后台服务仍需保持运行。

验证包括服务器固定期限、到期拒绝、访问凭证期限封顶、旧凭证边界、并发轮换及实时连接到期；前端覆盖主动续期、并发401、请求幂等键、临时故障、页面重载、多窗口协调、退出竞争和24小时后重新登录。24小时边界采用可控测试时钟验证，不能描述为已连续运行24小时。
