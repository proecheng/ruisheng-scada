# 默认 RS485 点位表（38 个寄存器）

`default-rs485-38-points.csv` 按项目《修正后485点位表.docx》整理，用物理量名称替换泛化的寄存器名称。覆盖十进制零基地址 0～37，FC3、从站地址 1、16 位无符号“字”。CSV 为 UTF-8 BOM，字段与系统“点位配置 → 导入 CSV / 导出 CSV”一致。

本表用于已核对的 38 寄存器协议；不是所有型号设备通用表。新设备须确认协议相同；从站地址不同需先调整 dev_addr。

## 数值口径

模拟量名称带“原始值”，单位留空，点倍率及用户倍率均为 1、偏移均为 0；不把未换算的原始数值标成工程量。环境温度地址 35、环境湿度地址 36，原值分别除以 10 对应 ℃、%RH，例如 290、470 对应 29℃、47%RH。地址 31 是第 4 路 NTC 温度，32～34 为预留。

文档的功率因数倍率与实测值存在冲突，频率的 DATA 公式与 5000→50Hz 示例不一致，DI 的实测值与字节通道描述亦不一致。本表保持倍率和符号；DI 地址0按用户现场确认设为完整“字”采集、`display_bits=2`，原值3显示11。DO 地址1的 `display_bits` 留空，待确认回读值是相邻位还是高低字节各一路。后续工程值换算须同时考虑历史原值口径，不能只改当前采集倍率造成新旧历史混用单位。

`display_bits` 是显示路数，可填写1～16，留空为普通数值。它与 `bit` 提取单独一位不同。详细设置及DO指令核对见同目录的 `digital-state-display.md`（项目源码位于上一级目录）。

## 使用方法

- **空点位设备**：在“点位配置 → 导入 CSV”中选择本表，导入后应为 38 个点位。
- **已有点位设备**：当前导入接口会新增点位。不要再次直接导入；应按功能码、从站地址、寄存器地址匹配既有点位，在编辑页面调整名称和显示方式，保留点位 ID 和历史记录。
- **多路显示**：需使用支持 `display_bits` 的版本（`deploy-20260915.4`起）。数据类型选“字”，显示方式选“多位二进制（开关量）”，显示位数填写实际路数。系统“导出 CSV”可下载当前点位表。
