# DI / DO 多路开关量显示

`bit` 表示从寄存器提取某一位。位号0只取最低位，因此寄存器3会得到1；位号1也会得到1。这不是把整字转换为二进制。

同一个寄存器显示多路开关量时：数据类型选“字”，寄存器类型按设备协议选FC3或FC4；显示方式选“多位二进制（开关量）”，显示位数填写实际路数（1～16）。原始倍率和显示倍率都为1，两个偏移均为0。每个DI/DO点位可独立配置，配置保存在服务器，点位CSV通过`display_bits`列导入导出，空值表示普通十进制数值。

二进制从右向左对应第1路至第N路，位0是第1路。1表示高电平，0表示低电平。两路配置显示0→00、1→01、2→10、3→11；四路配置显示3→0011。页面同时逐路标明高低电平。具体DO高电平对应继电器吸合还是释放，以设备接线和协议为准。

无采样显示“—”，不会伪装成全低。值为负数、非整数或超出配置位数时显示状态超出范围及原值，不截掉高位、不把非零值一律转换为1。采集值和原有历史不因显示配置而重写。此前使用单bit采集的历史已经只保存该位，无法凭显示设置恢复当时未保存的其他位。

历史表、图表提示和导出附带同样的显示值与逐路状态；多位开关量曲线采用阶梯线。长时间范围降采样使用每个时间段内最后一条状态，模拟量仍取平均值，以免把开关量平均成不存在的状态。

实现将`display_bits`作为点位接口字段，保存在现有`device_static_data`设备静态键值表中，键为`point_display_bits:<point_id>`，值为路数。点位新增、修改、导入、删除与该元数据在同一事务中完成，写入均持有设备行锁；设备权限先由点位接口校验。读取按设备和点位标识关联，不依赖中文名称或硬编码地址。采集网关继续使用完整字类型，数据库结构保持`0013_serial_polling_profile`。

本设备DI地址0默认设为2路，依据用户现场确认的“3代表两路均高”。DO地址1的默认显示配置等待确认回读编码。原《修正后485点位表.docx》写高低字节各一路，与低位逐路排列的解释不同，未改原始协议文档。

用户提供的DO控制指令为FC05：线圈地址0对应LED0/PA6，地址1对应LED1/PA7；高电平写FF00，低电平写00FF（设备自定义，标准FC05低值为0000）。四条完整指令CRC均已离线核对。控制写法与FC03状态寄存器的编码分别处理，本功能不修改控制编码，不下发DO命令。仅凭控制指令无法断定FC03回读位序；确认之前不能用输出切换作自动测试。
